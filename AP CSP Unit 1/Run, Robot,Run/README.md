This is a sample of Activity 1.1.5 (Run, Robot, Run) from the PLTW CSP coursework. THIS IS ONLY FOR VIEWING PURPOSES, NOT FOR PLAGARISM OR CHEATING.

What is this activity?
This activity is a demonstration of Python Turtle module operators, such as the turn(), move(), and setheading()/right()/left() commands.
It utilizes a PNG file of a maze (Maze 1, 2, 3) that MUST BE DOWNLOADED with the specific maze (example: Maze I must have the Maze I PY file downloaded.)
The turtle object also must be downloaded with each PY file (robot.gif.)

Please enjoy this code sample!
