II - What is this repository?
Obviously, this repository is a portfolio of Python files from PLTW! However, this is more than a hoard of Python files. 
Many of the files demonstrate various functions of Python - such as loops, math methods, turtle graphics, and lots more.
All files are sorted by the assignment name, alongside what each file demonstrates.

The files are sorted this way:
- AP CSP Unit 1 (PLTW Activities 1.1.2 - 1.1.5). This is a demonstration of a variety of Python Turtle Graphics methods.
- The Unit 1 files include:
-   PLTW Activity 1.1.2 (basic turtle geometry)
-   PLTW Activity 1.1.3 (drawing and debugging a flower to specific constraints)
-   PLTW Activity 1.1.4 (drawing an Archimidean spiral with Turtle)
-   PLTW Activity 1.1.5 (setting an image as a turtle object, using commands to move the turtle, and setting turtle images as a background. Because 1.1.5 is in a folder, to open it in VS Code, you MUST download the 1.1.5 folder as a ZIP file.)
- Unit 1 also includes some other demonstrations, including:
-   Grandma Ester's Cookies (using for loops and while loops to repeat blocks of text)
-   Project STEM Addition (using the Order of Operations and mathematical operators in Python)

- AP CSP Unit 2 (PLTW Activities 1.1.6-1.1.8.) This is a demonstration of more Turtle methods, alongside the use of loops and other explicit Turtle methods.)
- The Unit 2 files include:
-   PLTW Activity 1.1.6 (using Turtle to debug an image and repair it)
-   PLTW Activity 1.1.7 (using collision detection to allow turtles to properly move.) PLTW 1.1.7 also includes an alternate version, where the turtle object is replaced with the DECODE Entertainment, Inc. logo mascot. Similar to Activity 1.1.5, the folder MUST be downloaded as a ZIP to work properly.
-   PLTW Activity 1.1.8 (using collision detection AGAIN, but having the turtles change size and color as soon as collided with.)
- Unit 2 also includes additional demonstrations, including:
-   Two Python array demonstrations (with and without Turtle)
-   A supplement to PLTW Activity 1.1.8 using a grade tracker, demonstrating for and while loops to calculate a test score
-   A Tip Percentage Function using if/elif/else statements

Please feel free to use this repository as inspiration, and please enjoy the beautiful code!
